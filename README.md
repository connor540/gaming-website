# PixelPulse

A dark-themed gaming website starter built with Next.js and Tailwind.

## Features
- Responsive homepage
- Games archive page
- Individual game review pages
- File-based content setup for easy editing

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy
This project is ready to be deployed to Vercel or other Node-compatible hosts.
